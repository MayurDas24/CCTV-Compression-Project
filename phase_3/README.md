# Phase 3 - Intelligent Frame Decision Layer

## Overview

Phase 3 is the decision-making layer of the AI CCTV Compression pipeline.

It consumes the object detection and frame importance metadata generated by
Phase 2 and determines which analyzed frames should be retained or dropped.

The goal is to reduce unnecessary video data while preserving frames that
contain important visual information.

## Pipeline

## Input

Phase 3 consumes:

    ../phase_2/outputs/perception.jsonl

Each record contains:

- Frame index
- Timestamp
- Frame dimensions
- Detected objects
- Object classes
- Detection confidence
- Bounding boxes
- Frame importance score

## Decision Logic

Each analyzed frame is classified according to its importance.

### High Importance

Frames with an importance score above the configured high threshold
are retained.

Example:

    importance_score >= 0.30

### Low Importance

Frames with an importance score below the configured low threshold
may be dropped.

Example:

    importance_score < 0.15

### Critical Objects

Frames containing critical objects such as people receive higher
priority and should be retained.

### Consecutive Frame Protection

The system limits the number of consecutive frames that can be dropped.
This prevents long gaps in the resulting video.

## Output

Phase 3 generates:

    outputs/frame_decisions.jsonl

and:

    outputs/summary.json

Contains one decision record for every analyzed frame.
